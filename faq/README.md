## 支付与开通

### Q：国内 Visa / 银联信用卡能不能买 ChatGPT Plus？

不能只凭 Visa / Mastercard 标识或发卡地区判断。OpenAI 网页结账支持信用卡、借记卡和多种币种，但所在地与付款方式仍要符合支持政策，最终结果也受发卡机构、卡片状态、账单信息和支付服务方影响。

所以"我有一张 Visa"不等于"我一定能自己充值"，也不能据此断言一定失败。中国大陆当前不在 OpenAI 公布的 ChatGPT 支持地区列表中；如果所在地或付款方式不受支持，不要尝试绕过。展开见 [国内 Visa 能不能买 ChatGPT Plus](../articles/chatgpt-plus-without-overseas-card.md)。

### Q：没有国外信用卡，怎么用支付宝 / 微信充值 ChatGPT Plus？

没有海外卡也有几条路，主要这几种：

- **第三方自助代充平台**：用支付宝 / 微信付款，平台帮你把 Plus 开到你自己的账号上。省掉一整套支付排查，但要自己会挑平台。
- **iOS 内购**：所在地受支持且官方 ChatGPT App 显示订阅入口时，可以在 App 内购买并由 Apple 管理订阅。

每种适合谁、要注意什么，详见 [主教程的方法对比](../README.md#summary)。核心是：先看自己属于哪类用户，再选路径，而不是硬刚国内信用卡。

### Q：国内信用卡为什么经常充值失败？

常见检查点包括所在地与发卡地区是否受支持、卡号和账单地址是否正确、余额与卡片状态、银行是否允许线上或国际订阅，以及 3D Secure / SCA 是否完成。OpenAI 通常拿不到银行的详细拒绝原因；连续失败时保存原始提示并联系发卡机构。详细排查见 [付款失败](../troubleshooting/payment-failed.md)。

## 第三方自助代充

### Q：第三方代充会不会要求给账号密码？

我把"是否要求账号密码或验证码"当成筛选红线。正常的自助流程**不应该**让你交出 ChatGPT 密码、邮箱密码或验证码。PlusGO 的自助流程提交的是临时会话凭证（access_token）；它不是密码，但在有效期内仍可能允许访问账号，属于敏感登录凭据，提交给第三方会带来账号安全与条款风险。相关服务说明见[主教程的方法二](../README.md#method-topup)。

### Q：一次性临时凭证和账号密码一样吗？

不是同一字符串，但安全意义接近：两者都可能被用于访问账号。OpenAI 条款禁止分享账号凭据或把账号提供给他人使用；即使第三方声称凭证会自动失效，也不能写成无风险。决定使用前应确认网址、用途、保存与删除方式，并理解可能的账号与隐私后果。

### Q：怎么判断一个代充平台靠不靠谱？

下单前至少过一遍这几条：**不要求密码、邮箱密码或验证码；如需临时会话凭证，明确用途、保存期限和删除方式；套餐周期和价格公开；有订单号可查；售后入口明确；不夸张承诺也不诱导高风险操作。** 完整清单见 [主教程的第三方平台自检清单](../README.md#checklist)。我会把登录凭据边界放在第一位。

### Q：通过代充平台开 Plus 会封号吗？

任何第三方都不能保证账号不会被限制。OpenAI 会根据服务条款、账号活动和安全机制独立处理限制或停用；不能把原因固定归结为住宅 IP、机房 IP 或代付动作。比较平台时应核对运营主体、订单可追溯性、凭证处理和书面售后边界。

### Q：充值成功后没看到 Plus 怎么办？

先做三件事：退出后重新登录；换无痕窗口或清缓存再看；确认提交的是不是当前正在用的账号。还是没变化就别反复重新下单，拿订单号联系售后。详见 [付款后账号状态不对](../troubleshooting/account-status.md)。

### Q：充值失败 / 已开通，退款怎么算？

分两种情况，下单前先看清平台条款：

- **充值失败、未开通成功** → 按平台条款处理；PlusGO 当前购买页写明失败订单当天原路退款，这是第三方售后条款，不是 OpenAI 承诺。
- **已经完成交付** → 是否可退、如何计算和处理时效以对应购买渠道的订阅、取消与退款规则为准。

## 价格、续费与管理

### Q：到期后会自动续费吗？

看你选的方式。自己订阅或 iOS 内购通常有订阅管理入口；第三方自助代充可能是单月商品，也可能提供 3 个月、12 个月等第三方服务组合。OpenAI 当前不为 Go、Plus、Pro 提供官方年付或一次预付多个月；下单前要看清第三方商品的按月交付、续费和退款规则。

### Q：开通之后怎么管理订阅？

- iOS 内购：在 Apple 的订阅管理里查看、取消、看账单。
- 自己用海外信用卡订阅：在账号设置的订阅页管理。
- 第三方自助代充：到期前回原平台再操作一次，留意续费说明。

不管哪种方式，建议留好订单号或凭证，方便后续查询和售后。

### Q：Plus 和 Pro 怎么选？

大多数普通用户先从 Plus 开始就够了。Codex 已包含在所有 ChatGPT 方案中，Free 和 Go 也有受限使用；Plus 提供更大的使用空间，Pro 更适合每天高频重度使用 ChatGPT 或 Codex、经常被额度或任务长度打断的人。Pro 主要增加相对 Plus 的 5× / 20× 使用额度，并提供当前 Pro 专属的 GPT-5.3-Codex-Spark 研究预览。自 2026 年 8 月 31 日起，使用 ChatGPT 账号登录 Codex 时，应以 GPT-5.6 Terra 替代 GPT-5.4、以 GPT-5.6 Luna 替代 GPT-5.4 mini；API 和使用自有 API Key 的 Codex 不受影响。详细判断标准见 [主教程：Plus 用满后要不要看 Pro](../README.md#pro)、[Codex 用 Plus 还是 Pro](../README.md#codex) 和 [OpenAI 官方 Codex 方案说明](https://help.openai.com/en/articles/11369540)。

### Q：ChatGPT 或 Codex 用量到顶后，OpenAI 客服能帮我重置吗？

不能要求客服手动或礼貌性地重置 ChatGPT / Codex 使用上限。先看 Usage 页面提供哪种选项：

- **正常周期重置**：等账号显示的时间自动恢复；
- **Banked Reset**：可能发到账号的一次性促销权益，需要手动使用且可能过期，不是购买的点数；
- **Automatic / Global Reset**：OpenAI 直接应用到符合条件的额度，不会保存成待用 Reset；
- **Credits / 点数**：套餐用量耗尽后的额外按量余额，购买资格和金额以账号页面为准。

如果怀疑计量错误、符合资格的 Reset 缺失，或显示的重置时间过后仍未恢复，可以联系 Support 调查；提交工单本身不等于会获得额外 Reset、点数或补偿。详细区别见 [Codex 点数充值、Reset 与 Pro 怎么选](../articles/codex-credits-recharge-guide.md)，官方说明见 [Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540) 和 [How banked Codex resets work](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)。

## 使用与账号

### Q：开通之后还要注意网络环境吗？

要。充值只解决订阅状态，日常使用仍需遵守 OpenAI 支持地区和账号规则，并避免在公共或不可信网络中提交账号、付款或会话凭据。

### Q：新账号可以马上升级吗？

OpenAI 没有公布“新账号必须等待若干天才能升级”的统一规则。能否购买应以账号页面、支持地区、发卡地区、付款方式和原始错误提示为准；页面没有入口或持续失败时，通过官方支持核对，不要反复尝试。

### Q：失败后怎么保存排查信息？

养成随手记录的习惯，找售后或自己判断时都用得上：

- 失败时的**报错原文**（截图或抄下来）。
- 当时用的**充值方式**和**账号邮箱**。
- 走第三方平台的话，记下**订单号**和**下单时间**。
- 失败在哪一步：打开支付页、提交付款、还是付款后没到账。

留好这些，比凭印象说"就是失败了"好排查得多。对照报错排查见 [排障清单](../troubleshooting/)。
