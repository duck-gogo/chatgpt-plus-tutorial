## 先说结论

- **点数是额外按量使用，不是新订阅。** 套餐内用量会先消耗，达到套餐上限后，符合条件的功能才从点数余额扣除。
- **能否购买以账号页面为准。** Plus / Pro 用户达到 Codex 上限时可能看到添加点数入口；OpenAI 也在向部分 Free / Go 用户提供购买能力，但会因账号、地区和方案而异。
- **OpenAI 官方点数与第三方充值要分开看。** PlusGO 当前点数商品面向其页面标明的 Plus / Pro 账号，这个商品范围不代表 OpenAI 对所有账号的统一限制。
- **Reset 不是点数。** Banked Reset 是可能发到账号的一次性促销权益；点数则是额外余额。两者的获得方式、使用方式和到期规则都不同。

## Codex 点数是什么，什么时候开始扣？

OpenAI 将点数定义为套餐之外的按量补充。购买点数不会改变你的 Free、Go、Plus 或 Pro 档位，也不会增加方案本身包含的固定用量。

扣费顺序很明确：

1. 先使用当前方案包含的用量；
2. 达到方案上限后，符合条件的功能才从点数余额扣除；
3. 余额、最近使用和重置时间，以账号的 Usage 页面为准。

在功能对当前方案开放的前提下，同一账号的点数可能由 Codex、ChatGPT Work、ChatGPT for Excel 等受支持功能共同使用。它们**不是 OpenAI API credits**，不能拿去抵扣 API 账单。

实际消耗取决于模型、任务复杂度、上下文、推理强度、运行位置和工具调用。不要把点数换算成固定的“可完成任务数”，也不要直接套用别人的消耗速度。

## 购买前先确认四件事

### 1. 账号有没有购买入口

先打开 ChatGPT 的 `Settings → Usage`，或 Codex App 的 `Usage & Billing`。如果账号支持购买，会显示相应入口、可选金额和付款方式；这些内容可能因账号、地区和方案而不同。

Plus / Pro 用户达到 Codex 上限时通常会看到添加点数选项。部分 Free / Go 账号也可能获得入口；看不到时，不能通过教程推断账号一定有资格。

### 2. 用完的是哪一类额度

Codex、普通 ChatGPT 对话、文件上传、图像和语音可能使用不同额度。先看限制提示和 Usage 页面，确认用完的是 Codex / agentic allowance，而不是另一个功能的独立限制。

### 3. 是临时补充，还是长期高频使用

- 偶尔在重置前差一点用量：少量点数更灵活；
- 每个周期都稳定触顶：比较 Pro 5× / 20× 的持续成本；
- 页面已有可用 Banked Reset：先看有效期和影响范围，再决定是否使用；
- 不着急：等待账号显示的正常重置时间，不产生额外费用。

### 4. 接受点数条款

OpenAI 当前说明，购买的点数通常不可退款（法律另有要求除外），自购买起有效 12 个月，过期不结转；点数不可转让、没有现金价值，也不能转售或赠送。

## 官方购买与第三方充值有什么区别？

**OpenAI 官方入口**在符合条件的账号 Usage 页面中。可选金额、价格、付款方式和自动充值能力都以该账号显示为准。

**第三方服务**有自己的商品范围、交付方式和售后条款。以 [PlusGO 的 Codex 点数购买页](https://plusgo.pro/purchase?sku=codex_credits&quantity=20&utm_source=github01) 为例，当前列出约 500 / 1,000 / 2,500 / 5,000 点数的快捷档位，页面标明通常约 30 分钟内完成，并把适用账号限定为 Plus / Pro。快捷档位只用于选档，最终到账余额、消耗和可用功能仍以 OpenAI 账号显示为准。

第三方页面的套餐范围、交付时效和退款承诺属于第三方服务条款，不是 OpenAI 的承诺。下单前应重新核对页面，并把临时会话凭证等信息视为敏感登录凭据；不要提交密码、邮箱验证码或一次性验证码。

## 点数、正常重置、Banked Reset 有什么区别？

| 选项 | 它是什么 | 怎么生效 | 适合场景 |
|---|---|---|---|
| 正常周期重置 | 套餐额度按账号显示的周期恢复 | 到时间自动发生 | 不急着继续任务 |
| Banked Reset | 保存到账号的一次性促销权益 | 在 Usage 页面手动使用，未使用前可能过期 | 账号明确显示有可用 Reset |
| Automatic / Global Reset | OpenAI 针对符合条件额度直接执行的重置 | 自动应用，不会保存成待用 Reset | 以具体公告和账号结果为准 |
| Credits / 点数 | 套餐上限后的额外按量余额 | 购买后在受支持功能中按实际使用扣除 | 重置前需要临时继续工作 |

使用 Full Banked Reset 会刷新符合条件的 Codex 5 小时和每周窗口，并改变每周重置日期。它不是购买的点数，也不会永久提高方案额度；资格、发放时间和有效期由具体活动决定，未来是否还有不能保证。

OpenAI Support 不会手动或礼貌性地赠送 Reset。若账号本应获得的 Reset 缺失、使用后未正确生效或计量明显有误，Support 可以核查资格和错误，但提交工单本身不等于会获得额外 Reset、点数或补偿。

## 点数和升级 Pro 怎么选？

| 情况 | 更值得先看 |
|---|---|
| 偶尔触顶，离重置只差一个临时任务 | 少量点数 |
| 每个周期都触顶，长期做重任务 | Pro 5× / 20× |
| 账号显示有即将过期的 Banked Reset | 先核对并使用 Reset |
| 不急，且不想增加支出 | 等待正常重置 |

升级 Pro 会改变订阅档位和持续额度；购买点数不会改变方案，只补充受支持功能的额外使用。比较时应看一个完整周期的实际消耗，不要只看单次任务。

## 常见问题

### Free / Go 能购买 Codex 点数吗？

OpenAI 当前向部分 Free / Go 用户提供点数购买能力，但是否开放会因账号、地区和方案而异，以 Usage 页面是否出现 `Add credits` 为准。PlusGO 当前第三方商品另行限定为 Plus / Pro 账号，这不是 OpenAI 的统一资格规则。

### 买了点数，会立刻改变套餐额度吗？

不会。原方案不变，套餐内用量仍优先消耗；达到上限后，符合条件的功能才从点数余额扣除。

### 点数会自动恢复或永久保留吗？

不会自动恢复。OpenAI 当前说明购买的点数有效 12 个月，未用完会在到期后失效，不会滚存到下一有效期。

### 点数可以用于 API 吗？

不可以。这类 ChatGPT / Codex 点数不是 OpenAI API credits。

### 联系 Support 能让额度重置吗？

不能要求 Support 手动重置。计量错误、符合资格但 Reset 缺失或重置时间过后仍未恢复时，可以提交时间、时区、Usage 页面截图、客户端和模型，让 Support 调查。
