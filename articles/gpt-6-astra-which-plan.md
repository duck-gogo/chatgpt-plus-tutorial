GPT-6 Astra 已发布，面向代码、应用和研究中的复杂多步骤工作。如果正在考虑为它升级，我会先确认两件事：自己常用的界面是否已经开放，现有套餐的使用量是否能覆盖实际任务。模型更新本身不要求已有 Plus 用户退订重买。[Astra 更新说明](https://learn.chatgpt.com/docs/whats-new)、[模型与可用性](https://learn.chatgpt.com/docs/models)。

## 先确认在哪个界面使用

普通 Chat 中的 **GPT-6 Pro 由 GPT-6 Astra 驱动**；Work / Codex 使用 Astra 名称。两者不是“模型名称一样，所有套餐就都有同样入口与次数”，工作区内还可能受管理员设置影响。

**Work / Codex** 共享使用量，不能各算一份，也不能把它们的用量表套到普通 Chat。Work / Codex 余量看 [Usage 页面](https://chatgpt.com/codex/settings/usage)，普通 Chat 则看模型提示中的限额与重置时间。[套餐与计量说明](https://learn.chatgpt.com/docs/pricing)。

| 当前套餐 | 普通 Chat 的 GPT-6 Pro | Work / Codex 与购买提醒 |
|---|---|---|
| Free / Go | 当前未列为包含该模型的方案 | 受限 Codex 体验不等于包含 Astra |
| Plus | 不包含 | 包含 Astra，仍有用量和客户端要求 |
| Pro 5× | 包含，有模型周限额 | 包含 Astra，提供较 Plus 更高的 Work / Codex 用量；当前可新购 |
| Pro 20× | 包含，有模型周限额和合计日限额 | 包含 Astra；官方常规新购／升级暂停，PlusGO 新开通与存量续订条件见下文 |
| Business / Enterprise | 包含，需符合工作区权限 | 另核对席位版本、计量方式、管理员启用与组织开放条件 |

依据：[GPT-5.6 与 GPT-6 Pro 的官方套餐范围](https://help.openai.com/en/articles/20001354-gpt-56-in-chatgpt/)。5× 的两个 Pro 模型共用周额度，不能切模型“再拿一份”；20× 则有各自限额和合计日限额，具体次数与关系见 [Pro 指南的 Chat 限额表](https://github.com/duck-gogo/chatgpt-pro-tutorial#astra)。

Enterprise 的初期开放还涉及组织资格和管理员启用，单纯修改默认模型不会取得额外权限。[工作区模型可用性](https://learn.chatgpt.com/docs/enterprise/workspace-model-availability#gpt-6-astra-in-enterprise)。

## 哪些任务值得考虑 Astra

我会优先拿需要多步执行和核对结果的任务来评估，例如：

- 修改一组相互关联的代码，并运行测试检查结果；
- 对照多份材料完成研究报告，保留引用并复核结论；
- 按公司的模板整理文档、表格或演示稿，再检查是否遗漏要求。

这是选任务的建议，不代表每次执行都能成功或无需人工复核。简单翻译、短问答、固定格式整理，也可以继续使用已满足需要的模型。给出材料、范围和验收要求，通常比只换一个更高档套餐更有助于判断效果。

## Plus、Pro 5× 和 20× 怎么选

**需求已明确时，可以直接比较 Pro，不必先购买 Plus。** 自 9 月 10 日起，官方常规入口暂停 20× 新订阅与升级；PlusGO 当前另有新开通与存量续订，按下方账号和周期条件确认，不代表官方恢复，也不保证以后随时能补差升级。[官方暂停说明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-plans)。

| 使用情况 | 可以考虑的选择 |
|---|---|
| 轻量使用，现有额度能完成 Work / Codex 任务 | 保留 Plus，先用实际任务评估 Astra |
| 需要普通 Chat 中的 GPT-6 Pro | 评估 Pro 5× 的模型周限额；不只比较 Work / Codex 倍数 |
| 每天持续编码、研究或处理文件，明确需要更大用量 | 比较 Pro 5×，同时核对所需功能是否可用 |
| 5× 已多次在重置前耗尽，后续工作仍然密集 | 区分限额类型，比较任务设置、等待、点数或符合 PlusGO 条件的 20× 新开通完整成本，不默认补差或额度重置 |
| 已有有效 Pro 20×，希望继续使用 | 到期前核对续订，不把取消后另行新开通当成保底方案 |
| 只在短期项目中偶尔缺少额度 | 比较等待重置、调整模型或额外点数 |

Pro 两档的官方美元月价分别是 **$100 / 月（5×）**和 **$200 / 月（20×）**。更高用量不等于固定消息数、固定工作时长或更好的结果；任务复杂度、上下文、推理强度和工具使用都会影响消耗。第三方人民币报价与官方美元月价应分开比较，付款金额以实际结账页为准。[官方套餐与用量](https://learn.chatgpt.com/docs/pricing)。

需要完整开通步骤，继续看 [ChatGPT Pro 充值教程](https://github.com/duck-gogo/chatgpt-pro-tutorial)；只想补充短期用量，见 [Codex 点数、Reset 与升级怎么选](./codex-credits-recharge-guide.md)。

## 已有 Plus 或 Pro，付款前确认换档影响

我会先记录当前档位、到期时间和用量，再核对目标商品是否接受已有订阅的账号，以及新周期、旧订阅剩余时长如何处理。

如果考虑第三方服务，先读 [Pro 新开通与续订清单](https://github.com/duck-gogo/chatgpt-pro-tutorial/blob/main/articles/pro-20x-pause-and-renewal.md)，并核对 [PlusGO 当前新开通与续订公告](https://plusgo.pro/blog/chatgpt-pro-20x-renewal-notice/?utm_source=github01&utm_medium=article&utm_campaign=astra_pro_202609)。当前要分开处理：

- 官方常规入口仍暂停 20× 新购与升级，第三方可售方案不表示官方恢复；
- PlusGO 的 20× 新开通接受当前 Free、Go、Plus 或 Pro 5× 且能正常网页登录的账号，从充值完成日起算 1 个月，不叠加原剩余时间；到期不自动续费，不保证后续可再次订阅，付款前另读清退款限制；
- PlusGO 的 Pro 5× 覆盖开通重新计算 1 个月，不叠加原订阅剩余时间；
- 有效 20× 老用户按页面先核验再续订，到期扣费成功后接续 1 个月并保留剩余时间，不能套用覆盖规则；仍显示 20× 但状态异常先咨询，不自行按正常新开通或有效续订下单；
- Codex 额度可能只补足新旧套餐差额，也可能重置，不能把重新开通理解成保证立即补满额度。

20× 官方常规新购／升级暂停来自 OpenAI；新开通覆盖和到期续订流程则是 PlusGO 的购买条件，不是官方补差升级。通过原渠道管理官方订阅时，应单独查看确认页的费用与生效时间。购买后仍需遵守账号、地区和用量规则。

## 订阅正常，为什么还看不到 Astra

1. 确认登录的是付费账号，以及正在使用个人空间还是公司工作区。
2. 确认当前是在普通 Chat、Work 还是 Codex；桌面端手动打开 `Menu → Check for Updates`，Codex CLI 使用 Astra 至少需要 `0.153.0`。
3. 区分“没有模型入口”和“用量已经耗尽”；Chat 看模型限制提示，Work / Codex 看 Usage，不通过重复续费来重置。
4. 公司工作区联系管理员确认可用模型、成员权限与组织开放资格。
5. 仍不明确时，向 OpenAI 支持提供脱敏截图、时间、客户端版本及当前套餐；不要重复充值验证入口。

若账号套餐或有效期本身没有按订单变化，再按 [付款后账号状态排查](../troubleshooting/account-status.md) 处理订阅问题。

## 公司为员工购买 Pro，需要选 Business 吗

不一定。可按需求比较个人 Plus、Pro 5×；考虑 PlusGO 的 20× 新开通时，逐个核对账号与购买限制，与有效 20× 的续订单列询价，批量范围咨询时确认。需要统一工作区、成员管理和团队数据政策时，再比较 Business。公司付款不会让个人 Pro 自动具备 Business 或 Enterprise 的组织能力。

采购和财务同事可以直接使用 [公司统一采购 Plus / Pro / Business 的清单](./chatgpt-enterprise-procurement.md)。
