ChatGPT Pro 现在有 $100 / 月的 5× 档和 $200 / 月的 20× 档。能否报销取决于真实业务和公司制度；实操中常见问题是：**凭证链不符合财务要求，或走账方式、会计科目没有提前确认。** 这篇梳理从准备凭证到提交财务审核的流程。

## 先说结论

ChatGPT Pro 能不能顺利报销，就卡在两点：

1. **凭证链是否符合公司要求。** 官网订阅通常提供境外 invoice，还应保留订单、付款记录和业务用途说明；国内第三方平台可能提供**增值税电子普通发票**（公司抬头 + 税号）。
2. **按什么方式走账。** 个人垫付后报销，还是公司公对公直付——Pro 金额大，推荐走对公。

把这两点理顺，剩下就是走公司正常的报销流程。下面拆开讲。

------

## 第一步：先确认公司需要的凭证链

官方订阅通常提供**美元境外 invoice**，它没有中国发票代码和销售方统一社会信用代码，但并非天然不能报销或入账。国家税务总局公开口径指出，企业从境外购进货物或劳务发生的支出，可以境外发票、具有发票性质的收款凭证及相关税费缴纳凭证作为税前扣除凭证；税务机关有疑义时可能要求补充证明。参考：[国家税务总局答复](https://www.chinatax.gov.cn/chinatax/c102449/c5222168/content.html)。

如果公司更习惯使用国内增值税发票，可以向支持开票的第三方平台确认以下信息：

| 要素 | 怎么填 |
|---|---|
| 发票类型 | 增值税电子普通发票（是否接受由公司财务审核） |
| 抬头 | 公司全称（和营业执照一致） |
| 纳税人识别号 | 公司统一社会信用代码 |
| 开票类目 | 一般是「信息系统服务 / 信息技术服务」 |

以 PlusGO 为例，其当前购买页说明支持增值税电子普票和公对公付款；这些属于第三方服务条款，不是 OpenAI 官方开票能力。具体凭证差异见 [ChatGPT 充值能开发票吗](./chatgpt-plus-invoice-reimbursement.md)。

## 第二步：选走账方式

### A. 个人垫付 + 事后报销

- **适合：** 金额不大、公司报销流程灵活、自己先用着。
- **怎么走：** 你用支付宝 / 微信先付，拿到开给**公司抬头**的发票，填报销单 + 附发票和付款记录，走公司报销。
- **注意：** 如果公司要求公司抬头和税号，应在付款前确认；个人抬头能否报销由公司制度决定，不能一概而论。

### B. 公司公对公直付

- **适合：** 金额较大、流程规范的团队。**Pro 5× 为 $100 / 月，Pro 20× 为 $200 / 月，金额较高时推荐走这种。**
- **怎么走：** 公司对公账户付款，发票直接开给公司，钱和票都在公司这边，不用员工垫付。
- **注意：** 下单前跟平台客服说明要走公对公，确认收款方式和开票信息。

------

## 第三步：财务怎么入账（会计科目参考）

增值税普通发票可以作为**成本费用凭证之一**，但能否入账、税前扣除以及是否需要订单和付款记录，应结合真实业务和公司制度判断。普票通常不能用于进项税抵扣；专票抵扣也需要满足相应条件。常见的入账科目参考如下：

| 使用场景 | 常见计入科目 |
|---|---|
| 一般办公 / 通用提效工具 | 管理费用 — 办公费 / 软件服务费 |
| 技术、IT 部门订阅 | 管理费用 — 技术服务费 / 信息服务费 |
| 研发团队用于项目研发 | 研发费用 — 软件 / 技术服务费 |

> ⚠️ 入账科目和税务处理，最终以**贵司财务口径和所在行业**为准。这里只给常见做法做参考，具体怎么计、能不能税前扣除，听公司财务和税务的。

## 完整报销 checklist（员工视角）

```
[ ] 下单前确认平台能开「增值税普通发票」、能开公司抬头
[ ] 准备好公司全称 + 统一社会信用代码（税号）
[ ] 金额大就走公对公；个人垫付则用本人支付宝 / 微信
[ ] 充值完成后联系客服开票，核对抬头和税号无误
[ ] 收到电子发票（PDF / OFD），检查抬头、税号、金额、类目
[ ] 报销单 + 发票 + 付款记录（订单号 / 流水）三件套一起交财务
```

留好「订单号 + 付款记录 + 发票或 invoice」，并按财务要求补充合同或业务用途说明。

## 几个容易踩的点

- **抬头、税号别填错。** 和营业执照不一致，财务大概率打回重开。
- **官方月付 vs 第三方多月组合。** OpenAI 当前不为 Go、Plus、Pro 提供官方年付或一次预付多个月；第三方页面上的多月商品属于服务组合，应按购买页写明的交付和开票方式报销。
- **报销时效。** 别等票过了公司报销周期才交，发票和付款尽量同月或同季度处理。
- **普票 ≠ 专票。** 普票可作为凭证之一，但不保证一定通过报销或入账审核；要专票抵扣进项的，下单前先问平台能不能开，并向财务确认抵扣条件。

## 常见问题 FAQ

### Q：增值税普通发票能入账报销吗？

普票可以作为成本费用凭证之一，但不能脱离真实业务、公司制度和其他材料单独保证“正常入账没问题”。是否接受、计入哪个科目、能否税前扣除，以及是否需要订单和付款记录，应由公司财务结合实际业务判断。专票还涉及一般纳税人进项税抵扣条件，不能简单概括为只有票种差异。

### Q：能开增值税专用发票（专票）抵扣吗？

要看平台和实际销售主体。公司需要专票抵扣进项的，应在下单前确认平台能否开具、业务类目是否匹配，并向财务核对抵扣条件。

### Q：开个人抬头能报销吗？

看公司制度。多数公司报销要公司抬头 + 税号入账；个人抬头能不能报，问你们财务。

### Q：ChatGPT Pro 可以官方年付吗？

目前不可以。OpenAI 官方说明 Go、Plus、Pro 不支持年付或一次预付多个月。若第三方平台提供多月服务组合，报销时应按第三方订单、实际付款和发票处理，并明确它不是 OpenAI 官方 Pro 年付。

### Q：哪家代充能开发票、走公对公？

不是所有第三方平台都能开票。PlusGO 当前购买页说明支持增值税电子普票和公对公付款；是否符合贵司报销要求仍需财务确认。怎么整体挑平台见 [主教程的第三方平台自检清单](../README.md#checklist)。
